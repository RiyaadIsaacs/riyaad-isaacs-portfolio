# Showcase print pack — what you need to do

Templates are in this folder. QRs are already generated. Layout matches your portfolio colours.

## 1. Contribution text

Already filled from your notes (player controller across projects; game manager/spawning on HELLp + Mirror Split; combat/menu/roguelike systems on Poaching Patrol). Edit the HTML if you want different wording.

## 2. Add photos (optional but strongly recommended)

Boards follow a portrait layout like the example: header → hero banner → text column + image masonry → tech + QRs.

Put extra images in `print/assets/photos/`:

| File suggestion | Use on |
| --- | --- |
| `mirror-gameplay.jpg` / `mirror-process.jpg` | Mirror Split gallery placeholders |
| `hellp-gameplay.jpg` / `hellp-process.jpg` | HELLp gallery placeholders |
| Poaching process shots | Already wired (`process-01` … `process-04`) |

Drop the files in, then swap the dashed placeholders in the A3 HTML for `<img>` tags — or ask me to wire them.

## 3. Export PDFs

For each of the 4 HTML pages:

1. Open the file in Chrome/Edge  
2. `Ctrl+P`  
3. Destination: **Save as PDF**  
4. Paper size: **A2** (poster) or **A3** (brag boards)  
5. Layout: **Portrait** for A2 and A3  
6. Margins: **None**  
7. Background graphics: **On**

## 4. Print

Take the 4 PDFs to a print shop:

- 1× A2 poster  
- 3× A3 brag boards (portrait)

Ask for colour, matte or satin, and board/foam mounting if your stall needs it.

## 5. Canva alternative (if you prefer)

1. Canva → Custom size → A2 `420 × 594 mm`, A3 `297 × 420 mm` (portrait)  
2. Screenshot or PDF-export these templates as a visual guide  
3. Recreate blocks in Canva and upload the same photos + QR PNGs from `assets/qr/`

You do **not** have to use Canva if PDF-from-browser looks good.
