How to get the A3 brag boards

  1. Click an A3 link above (start with Poaching Patrol).
  2. Press Ctrl+P (Print).
  3. Destination: Save as PDF.
  4. Paper size: A3.
  5. Layout: Portrait.
  6. Margins: None.
  7. More settings → turn Background graphics On.
  8. Save (e.g. A3-Poaching-Patrol.pdf).
  9. Repeat for Mirror Split and HELLp.
  10. Take the 3 PDFs + A2 PDF to a print shop and ask for colour A3 / A2 prints.
